# فكة — الصفحة التسويقية

صفحة هبوط عربية RTL لتطبيق فكة. تصميم v2 (IBM Plex Sans Arabic، `#0B6E56`، `#C9A84C`، `#F6F4EF`).

- النسخة التجريبية: https://fakka-prototype.onrender.com/
- لا تستخدم شعار نفاذ الرسمي ولا شارات متاجر آبل/جوجل الرسمية.
- لا إحصاءات أو شهادات وهمية.

هذه صفحة ثابتة للعرض، وليست تطبيق فكة الإنتاجي.
